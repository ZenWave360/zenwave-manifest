# ZenWave Schemas

Published JSON Schemas for ZenWave formats.

## URLs

- `https://schemas.zenwave360.io/zenwave-architecture/1.0/schema.json`
- `https://schemas.zenwave360.io/zenwave-architecture/latest/schema.json`

## Layout

- `zenwave-architecture/1.0/schema.json` - versioned schema
- `zenwave-architecture/latest/schema.json` - current stable schema alias

## GitHub Pages

This repository is intended to be served by GitHub Pages with the custom domain in `CNAME`.

## Manifest usage

```yaml
# yaml-language-server: $schema=https://schemas.zenwave360.io/zenwave-architecture/1.0/schema.json
```
